# NewsReader — 一次开发多端部署新闻阅读器

基于 HarmonyOS 断点系统实现的多设备自适应新闻阅读器，同一套代码在手机、平板、大屏上呈现不同的 UI 布局。

## 项目结构

```
Lab6/
├── AppScope/app.json5
├── build-profile.json5
├── entry/src/main/
│   ├── ets/
│   │   ├── entryability/EntryAbility.ets   # 标准入口
│   │   ├── pages/Index.ets                 # 主页面，根据断点切换三种布局
│   │   └── model/
│   │       ├── NewsData.ets                # 文章数据模型 + 分类定义
│   │       └── NewsApi.ets                 # 真实 API 请求 + 离线数据回退
│   └── module.json5                        # deviceTypes: phone, tablet, 2in1
└── hvigor/
```

## 功能

| 功能 | 说明 |
|------|------|
| 分类切换 | 科技、体育、财经、科学、健康、娱乐 6 个分类 |
| 新闻列表 | 带标题、来源、时间的卡片列表 |
| 文章详情 | 点击查看完整内容 |
| 真实 API | 对接 newsdata.io 获取真实新闻（失败时回退离线模拟数据） |
| 断点适配 | 手机/平板/大屏三种完全不同的布局 |

## 三端布局

| 断点 | 宽度 | 设备 | 布局 |
|------|------|------|------|
| **sm** | 320—600vp | 手机竖屏 | 单栏：横滚分类 → 新闻列表 → 点击跳详情（栈式导航）|
| **md** | 600—840vp | 平板/折叠屏展开 | 双栏：左侧 35% 列表 + 右侧 65% 详情 |
| **lg** | 840vp+ | 2-in-1/智慧屏 | 三栏：左侧 15% 分类 → 中间 30% 列表 → 右侧 55% 详情 |

## 核心技术

- `@StorageLink('currentBreakpoint')`：响应系统断点，自动切换布局
- 条件渲染：`if/else` 根据 `this.breakpoint` 值切换三种 Column/Row 结构
- 组件复用：`CategoryBar`、`NewsListPanel`、`ArticleDetailPanel` 三个 `@Builder` 在所有断点下共享
- `@ohos.net.http`：真实 HTTP 请求获取新闻数据

## 要求

- DevEco Studio 6.0.2+，API 12 (5.0.0)
- 联网权限（获取新闻数据）
- 三种断点效果可在模拟器多设备预览中同时查看
- 需要在 `local.properties` 中配置 SDK 路径
